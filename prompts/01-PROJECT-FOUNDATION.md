# 01 — Fundação do projeto

## Objetivo
Inspecionar e preparar a base técnica/documental sem implementar funcionalidades públicas.

## Contexto
O checkout inicial continha README legado, sem aplicação ou dependências. Confirme o estado atual antes de agir.

## Escopo
Inventário, decisões de stack, estrutura mínima e documentação de fundação; sem construir o site ou painel.

## Requisitos
Ler `AGENTS.md`, README, docs e configurações presentes; preservar conteúdo existente; comparar opções com requisitos; explicitar decisões pendentes; não instalar dependências até stack aprovada.

## Entregáveis esperados
Relatório de estado confirmado, escolhas justificadas e documentação coerente atualizada.

## Critérios de aceite
Nenhuma funcionalidade especulativa descrita como implementada; decisões futuras claramente marcadas; comandos só documentados se existentes.

## Referências
`AGENTS.md`; `docs/ARCHITECTURE.md`; `docs/ROADMAP.md`; `docs/DEPLOYMENT.md`.
